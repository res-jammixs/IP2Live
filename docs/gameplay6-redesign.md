# Gameplay 6: Subnet Blaster

Gameplay 6 replaces the multi-connector matrix with a canvas arcade console for network and broadcast address analysis. The existing gameplay ID (`ip_cidr_quarantine_matrix`), quest ID, tile, manager API, pause integration, practice unlock and completion callback remain in place.

## Encounter flow

1. Read the given address, class and either borrowed bits or remaining host bits. The preparation console shows only a gently blinking "PREPARATION PHASE" heading in the Abnes display font, a small text timer and a circular skip icon. Hovering the icon fades in plain "Skip preparation" text below it over 180 ms, with no tooltip container. Prepare for up to one minute or press Enter/Space to skip. The calculator and optional H-key pilot briefing pause the countdown. The tutorial introduction runs before preparation on the first guided launch and on explicit tutorial replays; ordinary retries, restored games and unguided practice skip it.
2. Aim at one of three barriers to choose the addition/subtraction operator. Selection shows the heading (without a stage number), each choice and its short description. The question subtitle, module labels, targeting caption and bottom instruction are removed. The ship fires automatically every 160 ms; ten impacts break a barrier. Its text floats into the formula bar before the next wave opens.
3. Collect the numeric block size (`2^h`) in the second and final barrier wave. Infer host bits mentally or with the calculator: subtract borrowed bits from the class's default host-bit count, or use the given host bits directly. Every choice is collected, including incorrect ones. Distractors distinguish total addresses from usable hosts and exponentiation from multiplication.
4. APEX enters the arena. Five actual bullet impacts are required before it judges the two-module weapon; the first four only produce impact flashes. Correct formulas remove one shield segment: APEX glows red, vibrates, sheds pixel fragments, loses HP with an animated bar, releases the requested address and retreats. The address is a bare, glowing pickup with particles, rather than a result screen. It drops from the boss, remains readable in the arena for 2.6 seconds, then follows a curved 950 ms path into the answer field. The field stays unanswered until the pickup arrives. Scars, chipped armor and missing wing hardware persist into later encounters.
5. Incorrect formulas still reach APEX. It retains its HP, charges a return shot and attacks the ship, removing exactly one heart per failed encounter regardless of how many pieces were wrong. APEX then retreats without revealing the answer, highlighting individual mistakes or displaying AR diagnostic feedback.
6. After the address lands and briefly illuminates its field, the next question appears automatically. Given values and changing labels, the formula's given address, empty slots and endpoint correction erase and type into their fixed positions over about 825 ms. The full one-minute preparation timer starts after typing finishes; Skip completes typing immediately. Enter can advance after the address has landed, but cannot bypass the drop and transfer. Three recovered cores win; losing all three hearts ends the run after APEX retreats. Earned boss damage persists.

Each clean three-core run covers A, B and C once, in shuffled order, both question directions, and both types of bit givens. Failed encounters retain their current class until its core is recovered. Questions and barrier positions are randomized. There is no response deadline after the planning phase.

Address-drop and typing progress pause with dialogue and helper overlays and survive JSON save/restore. Older v4 result states join the new drop sequence without resetting the encounter or applying boss damage again. Reduced-motion mode keeps the address stationary until it fills the field, and displays new question text immediately. Guided introductions finish any text transition before highlighting the given values.

## Subnetting corrections

The tutorial follows Gameplay 5's approach: welcome the player, then teach each step with compact dialogue and highlighted controls. Preparation guidance reads the actual given and requested address, explains that values vary, illustrates the range from the first (network) to the last (broadcast) address, works out host bits and `2^h` using the current question, then explains the built-in endpoint correction and one-minute planning period. For example, Class C with three borrowed bits gives `h = 8 - 3 = 5`, then 32 total addresses rather than 30 usable hosts.

Operator and block-size lessons appear only when their respective barriers are visible. The boss lesson waits until APEX arrives, highlighting its HP, the assembled formula and the player's three hearts while explaining the five-hit check. Each slide has at most two points; later questions let the player apply the steps independently. Dialogue pauses preparation, auto-fire and encounter timers. Highlight rectangles follow the letterboxed canvas, and compact panels leave their subjects visible. A save restores the remaining guided phases without replaying the welcome or retaining a vanished dialogue's input lock. The H-key briefing and recovery reminder use the same subnetting terminology.

- A/B/C supply historical starting prefixes /8, /16 and /24, hence 24/16/8 default host bits. The derived prefix, not the class name alone, defines a subnet.
- If borrowed bits `s` are given, `h = default host bits - s`. If remaining host bits `h` are given, use them directly. The resulting prefix is `32 - h`.
- Block size means **total addresses in the subnet**: `2^h`. It includes the network and broadcast endpoints. Conventional usable host capacity is `2^h - 2`.
- `broadcast = network + 2^h - 1`; the inverse is `network = broadcast - 2^h + 1`. Adding the block without subtracting one reaches the next subnet's network address.
- Arithmetic operates on the complete unsigned IPv4 address, carrying across octets. For example, `172.16.0.0/19` has 13 host bits, 8,192 total addresses, and broadcast `172.16.31.255`.
- Conventional broadcast exercises exclude /31 and /32, which have special endpoint semantics. Generated examples use private ranges 10/8, 172.16–31/16 and 192.168.x/24. Zero-indexed and final subnets are allowed.

References: [Cisco: Understand Host and Subnet Quantities](https://www.cisco.com/c/en/us/support/docs/ip/routing-information-protocol-rip/13790-8.html), [Cisco: Configure IP Addresses and Unique Subnets for New Users](https://www.cisco.com/c/en/us/support/docs/ip/routing-information-protocol-rip/13788-3.html). The address equations follow from the first address having all host bits zero and the last having all host bits one.

## Controls and verification

Formula screens use slim 28-pixel housings and the same 17-pixel text size and vertical center as the surrounding address and arithmetic strings.

A/D, left/right arrows, 1/2/3, or the mouse aim at a lane. Firing is automatic; no fire button is needed. Barrier damage stays with that lane when aiming changes. Shots in flight are cleared when a barrier breaks, so extra bullets cannot spill into the next wave. C opens Gameplay 4.5's draggable host-power tool; H opens the briefing. Both freeze gameplay, including bullets and animation timers. Escape closes an overlay first, then opens the normal gameplay pause menu.

The console occupies about three quarters of the design canvas. Its layered metal frame uses corner plates, inset fasteners, luminous rails and edge vents. Combat shows a beveled, three-segment boss HP bar with gradient lighting and a delayed damage trail, plus hearts in the upper-right corner. Preparation hides that HUD. Signal numbers, recovered-core counters and the sector guardian heading are removed. The rectangular bottom dock uses graphic slash marks, halftone texture, ink-dark borders and bright edge cuts. Given values align in one column; the formula fills the remaining width. Operator, block-size and answer slots are recessed calculator screens with dark inner lips, glass highlights and fine scanlines. The requested address appears in the answer screen, replacing the redundant right-hand prompt. Glass barriers progressively crack and shatter. APEX has layered armor, floating energy particles and a layered plasma attack. The ship uses a faceted hull, cockpit, wing plates, vents, weapon mounts and twin exhausts. A blurred distant skyline, sharper foreground buildings, haze, vignette and stable fine grain add depth. Reduced-motion mode removes blinking, recoil shake, scenery/particle motion and pickup arcs while retaining transition timing and readable damage colors.

The calculator reuses `HostPowerToolManager` and `HostPowerToolScreen` with a dedicated block-size mode. Drag positive/negative bubbles to change h and see `2^h` total addresses. It shows only the current class and bit givens, uses neutral colors and never fills a formula slot or reveals the target exponent/prefix. Closing and reopening preserves the user's chosen exponent. Existing Gameplay 4.5/5 modes retain their previous readouts. The weapon, wave, bullets, barrier damage, floating pickup, animation phase, landed boss impacts, hearts and boss progress are JSON-safe for durable pause sessions. An unfinished earlier version starts a fresh arcade run; campaign quest progression stays intact. Reports record two evaluated formula decisions per encounter under `subnet-blaster-v4` while retaining historical readers. Developer tests return to the testing menu on completion, failure or cancel without advancing campaign quests.
